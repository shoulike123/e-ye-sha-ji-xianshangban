# 恶夜杀机 — 线上完整规则

> 现行完整规则书见仓库根目录 [`恶夜杀机规则书.md`](../恶夜杀机规则书.md)。  
> 下文部分条目（尤其是遭遇骰子）已经过时，冲突时以规则书与引擎为准。

## 编制

1 杀手 + 3 名幸存者棋子。线上可分控或热座，编制不因人数减少而少棋子。

## 胜负

**幸存者（三条独立的路）**

1. 公共钥匙架 5 把，且所有仍存活者都在主要出口。只在**幸存者阶段开始**检查。
2. 公共钥匙架 5 把，场上至少一人持有秘密地图，且所有仍存活者都在隐藏出口。同样只在幸存者阶段开始检查。
3. 第 5 次修理完成后，救援标记从 5 走到 0。**落到 0 的瞬间**立刻胜。

**杀手**

1. 任意幸存者从「受伤」再受到 1 点伤害 → 死亡 → 立刻胜。
2. 进入发现步骤时发现牌堆为 0，且修理尚未完成 → 立刻胜。

击杀即终局。不存在「死人不管、剩下的人撤离」。

不因此判负：发现牌空但修理已完成（跳过发现）；钥匙不到 5 或人没到齐；修理 1～4 次；救援还在 5～1。

## 检查时机

| 事件 | 何时查 |
|---|---|
| 钥匙撤离 | 幸存者阶段开始 |
| 救援推进 | 幸存者阶段结束（修满当回合只「放到 5」，不连推到 4） |
| 救援到 0 | 推进的瞬间 |
| 发现抽空 | 发现步骤开始 |
| 死亡 | 伤害结算的瞬间 |

走到出口的那一步若还在自己的行动段里，要等到下一次幸存者阶段开始才赢。

## 公开 / 隐藏（线上快照）

**始终公开**

- 每名幸存者：健康 / 受伤
- 每名幸存者：恐惧枚数（0 / 1 / 2）
- 每一次掷骰的每一个点数
- 公共钥匙个数（0～5）
- 救援是否已开始；开始后标记在 5 / 4 / 3 / 2 / 1 / 0
- 杀手等级，以及等级带来的力量等数值
- 所有幸存者技能、所有杀手技能/行动牌**牌面**（种类公开，手里有没有不是）
- 杀手非潜行位置与非潜行路径
- 封堵在哪些门上（变更立刻同步）
- 当前阶段、行动者、回合数、胜负

**对杀手隐藏（幸存者层）**

- 修理进度（1～4 次杀手完全看不见）
- 每名幸存者有多少件物品、是哪些（含秘密地图、手电筒、工具箱）
- 刚抽到、留下的搜索/发现牌（钥匙上架只公开「把数 +1」）
- 幸存者所在地点（默认）

**对幸存者隐藏（杀手层）**

- 杀手手牌的内容与张数
- 潜行期间的位置与路径

**同阵营**：3 名幸存者彼此可见位置、背包、修理进度。

曾写成「回合结束再口头报」的血量、恐惧、钥匙数：线上改为结算当下写入公开层。  
仍在阶段末统一推送的：普通噪音列表（发现之后、杀手阶段之前）。

## 地图

- 门和虚线都能走。**只有门能封**，虚线不能封。
- 距离：本格 = 0，一步邻格 = 1。秘密通道不是普通相邻。
- 实心墙不能穿。同格人数不限。红 / 蓝 / 绿区域供感知等整片结算。
- 庄园图一开局：幸存者 R1（主出口），杀手 G5（隐藏出口）。
- 木屋图二开局：幸存者 R1（主出口），杀手 B5（隐藏出口）。R5↔G2 黄虚线为杀手专用通道，常规移动消耗 1 行动力。
- 过秘密通道：持手电筒用**特殊行动**从一端到另一端。索菲亚「观察入微」可用特殊行动过通道；若她同时有手电筒，改为**额外行动**。

## 整局顺序

A. 幸存者阶段开始：清「本回合有效」噪音；检查钥匙撤离。  
B. 三名幸存者任意顺序，**一人做完再换下一个**，禁止交叉。  
C. 发现。牌堆 0 且无救援 → 杀手胜。  
D. 噪音报告给杀手。  
E. 幸存者阶段结束：若救援已启动，标记向 0 推进 1；到 0 立刻胜。修满当回合只把标记放到 5。  
F. 杀手阶段。遭遇则按遭遇结束规则收掉本阶段，回 A。  
G. 杀手阶段正常结束后回 A。

## 幸存者行动

每人一段。移动 / 消惊吓 / 拆封堵 / 特殊行动：每段各至多作主行动 1 次。  
**搜索**：每段可多次。  
**修机**：全队每幸存者阶段最多 1 次，必须噪音。  
与杀手同格：不能搜、不能修。不自动遭遇。

主行动前后、两次完整行动之间可多次做额外行动和交换。一次移动或一次搜索的中途不能插入。

- **移动**：沿门/虚线 1～2 步，一次走完，不过封堵，不把通道当普通边。
- **消惊吓**：清掉自己全部恐惧，立刻公开。
- **拆封堵**：拆本地点一块，立刻公开哪扇门。
- **特殊行动**：按技能/物品。无无限次标记的物品用完弃。
- **搜索**：须在搜索点、无杀手、牌堆非空。抽 1。钥匙立刻上公共架。其他进栏（默认 3，约翰逊 6），超限立刻弃到上限。左上角噪音牌无论留弃都吵。安娜在搜索点搜索不触发警报。
- **修机**：须在修机点、无杀手。默认 +1 且必须吵。工具箱按牌面提高进度；约翰逊用工具箱再额外 +1。进度只进幸存者快照。第 5 次完成等到本阶段结束才把救援标放到 5 并公开「已开始 / 在 5」。

**交换**：须同格；满栏也能换；换完各自不超自己的栏位；钥匙不能当物品换；交换内容对杀手隐藏。

## 发现

三人行动段全部结束后，指定 1 人摸 2 选 1；只剩 1 张则直接拿。没牌且修理未完成则求生者败（已修好则跳过发现）。噪音牌留不留都吵。**发现堆的钥匙也带响声**，要不要都会响；不要则进弃牌堆，钥匙架不加。留下哪张对杀手隐藏（除非因此增加公开钥匙数）。

## 噪音三种

1. **摸到就吵**（牌左上角）：只报格，本回合有效。  
2. **使用才吵**（技能栏标记）：只报格，本回合有效。  
3. **惊吓过度**：必须报**地点和人物**，当时有效；同步后拿掉噪音标，**前两枚恐惧留下**。

修理归入必须吵的本回合噪音。普通噪音 ≠ 人在这（爆竹可在别处放噪音）。

## 生命与恐惧

生命 2：健康 → 受伤 → 死亡（杀手立刻胜）。可用技能/物品回血，结果公开。**所有治疗须同地点**：只有在同一地点的求生者可以互相治疗（包括治疗自己）。草药仍在**使用者**所在地点发出响声。

恐惧：第 1、2 次各 +1 枚，场上最多 2。第 3 次（及之后在已有 2 枚时再被惊吓）= 过度：不上第 3 枚，立刻点名噪音。可用主行动/物品/技能消除，结果公开。

## 封堵

共 7 块。一扇门最多 1。虚线不能封。用完须先挪旧的。放 / 拆 / 转移立刻双向公开。  
幸存者不能过封堵。杀手普通移动过 = 拆。潜行过 = 不拆，路径仍隐藏。

## 杀手阶段

1. **潜行则重现**：公开当前格，撤潜行标，**强制一次不占行动的搜索**。搜到人则走遭遇并收回合。  
2. **快速卡牌阶段**：任意张快速牌。打出的牌名进公开日志；剩余手牌仍隐藏。  
3. **二选一（主要行动）**  
   - 执行 **2 个普通行动**。每个行动是「移动 1」或「搜索」，可以两次都移动、两次都搜索、或各一次。  
   - **或** 打出 **1 张特殊行动牌**（箭头一类）。  
4. 若未进入遭遇：**慢速卡牌阶段**，可打出手上的慢速行动牌（沙漏一类）。  
5. 杀手阶段结束（含遭遇结束后）：**抽 3**。手牌上限 5。牌库空则洗弃牌并升级（等级 1～5，力量上限 10，新等级与力量公开）。升级发技能超限时，杀手自选弃哪张（唯一自选弃牌）。

杀手搜索：问本格有没有幸存者，有则遭遇。空城不额外公开。

## 遭遇

仅由**杀手搜索命中**触发。幸存者走进杀手格、或杀手非搜索地走进幸存者格：不自动开战。

- 一场遭遇只能打 **1 张普通防御**。特殊牌可一次打多张。换人不得再打普通防御。  
- 基础 4 骰；每枚恐惧少 1 骰，最多少 2（即 4 / 3 / 2）。每个点数公开，服务器掷。  
- 总值 ≥ 杀手当前攻击力：防住，不受伤，杀手从**牌库**弃 2 张，整场结束。  
- 总值 < 攻击力：该人受伤（已受伤则死亡、杀手立刻胜）。同格还有人则**幸存者再选人**，不是杀手点名。  
- 牌库不够弃 2 张：先弃光，升级洗牌后再补弃。  
- 无人死亡则参与者各赠送移动 0～1，然后**立刻结束杀手阶段**（不再打剩余快速/特殊/慢速牌），但与没遭遇的回合一样**抽 3**。不插入一整段幸存者主行动/发现。

威廉「坚韧不拔」：未使用任何物品来增强防御时，防御总和 +1（加在牌+骰之后，不是多一张牌）。打出防御牌、掷骰都不算「使用物品」。使用短剑、长剑、石灰粉、手斧、弹药等加防物品即算使用物品——**短剑虽然可反复使用，用了就不能再触发坚韧不拔**，两者不能叠加。

## 引擎快照三层

- **公开层**：阶段、回合、行动者、hp/受伤、恐惧、钥匙数、救援开关与格、杀手等级与力量、是否潜行、杀手公开位置、封堵、技能全文、骰点、胜负、封堵/打出牌日志。  
- **幸存者层另加**：三人精确位置、三人物品栏、修理进度、搜索/发现待选与己方弃牌。  
- **杀手层另加**：杀手手牌、潜行中的精确位置、己方弃牌。  

修理进度**永不**进入公开层或杀手层。救援启动只写 `rescueArmed` + 当前格。  
物品数量与种类**永不**进入杀手层。杀手手牌张数也**不**公开。
